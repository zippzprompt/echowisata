# 🌿 EchoWisata – Explore Nature, Preserve the Future
https://echowisata-8h2e.vercel.app/

**EchoWisata** merupakan aplikasi web berbasis React yang mengusung konsep *Eco Tourism* atau wisata berkelanjutan. Project ini dikembangkan sebagai platform digital yang berfokus pada pengenalan dan eksplorasi destinasi wisata alam serta mendukung kesadaran masyarakat terhadap pentingnya menjaga kelestarian lingkungan.

Dengan tampilan antarmuka yang modern dan responsif, EchoWisata dirancang untuk memberikan pengalaman menjelajahi destinasi wisata alam secara lebih menarik, informatif, dan mudah digunakan.

## ✨ Tujuan Project

- Memperkenalkan konsep wisata ramah lingkungan.
- Mengembangkan platform digital untuk eksplorasi wisata alam.
- Memberikan pengalaman pengguna melalui antarmuka web yang modern.
- Mendukung promosi pariwisata berkelanjutan melalui teknologi web.

## 🛠️ Tech Stack

Teknologi yang digunakan dalam pengembangan EchoWisata:

| Teknologi | Deskripsi |
|---|---|
| React.js | Library JavaScript untuk membangun antarmuka pengguna |
| Vite | Build tool dan development server |
| Tailwind CSS | Framework CSS untuk styling antarmuka |
| React Router DOM | Pengelolaan navigasi dan routing |
| Lucide React | Library ikon untuk antarmuka |
| JavaScript | Bahasa pemrograman utama |
| HTML5 & CSS3 | Struktur dan styling halaman web |

## 🚀 Getting Started

Ikuti langkah berikut untuk menjalankan project secara lokal.

### 1. Clone Repository

```bash
git clone https://github.com/zippzprompt/echowisata.git
```

### 2. Masuk ke Folder Project

```bash
cd echowisata
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Jalankan Development Server

```bash
npm run dev
```

### 5. Buka Aplikasi

Akses alamat berikut melalui browser:

```text
http://localhost:5173
```
